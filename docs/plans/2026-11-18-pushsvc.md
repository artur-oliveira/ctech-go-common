# go-common `pushsvc` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract the product-independent half of the DF-e Web Push (subscription store, subscribe API, payload, sender core) plus a scheduled-reminder store into one go-common package, `pushsvc` (`v1.44.0`), for Poker and Billing.

**Architecture:** `pushsvc` sits on `webpush` (stateless crypto/VAPID) and `dynamo.Base`. It owns subscription rows and "reminder" rows (a user, a kind, a 15-minute BRT slot, a sent-day marker, a sparse GSI by slot). Each product owns its preference rules, tick and text. DF-e is not migrated here.

**Tech Stack:** Go, aws-sdk-go-v2 DynamoDB/SSM/Lambda, Fiber v3, `webpush`, `dynamo`, `problem`.

**Spec:** `ctech-poker/docs/specs/2026-11-18-scheduled-web-push.md` §4.1, §4.3. Port source: `ctech-dfe/api/internal/{repositories/push.go,services/push.go,services/push_events.go,cmd/push-sender/main.go}`.

## Global Constraints

- Module `gopkg.aoctech.app/api-commons`; new package `pushsvc`; tag `v1.44.0` (minor); update `CLAUDE.md` package list and add `pushsvc/README.md`.
- Table item shapes are DF-e's: subscription `pk=USER#{sub}`, `sk=SUB#{sha256(endpoint)[:16] hex}`; counter `sk=META#counts` attr `subscriptions`; `MaxSubscriptionsPerUser = 10`; subscription TTL `60*24h`, renewed on sync; GSI `endpoint-index` (pk `endpoint_id`).
- Reminder rows: `pk=USER#{sub}`, `sk=REMIND#{kind}`, attrs `enabled`, `slot`, `last_sent_day`; sparse GSI `slot-index` (pk `slot_key` = `SLOT#{NN}`, sk `kind_sub` = `{kind}#{sub}`), projection `KEYS_ONLY` (the tick needs only `kind` and `sub`, and both are in the key).
- Slots: 96 per day, `slot = (hour*60+minute)/15` in `America/Sao_Paulo` (import `time/tzdata`).
- Payload contract v1 is DF-e's (`webpush/testdata/notification-v1.json`, budget 1024 bytes, `lang pt-BR`). Never log an endpoint, key or payload; logs carry `sub_hash` (first 4 bytes of sha256, hex) and push host only.
- Tests: unit plus `//go:build integration` against DynamoDB Local on `http://localhost:8555` (pattern of `dynamo/query_integration_test.go`). `go test -race ./pushsvc/...`, `staticcheck`, `govulncheck` clean.
- No KMS, no SQS. No `Scan`.

## Review Focus

- Same endpoint registered by a second user (shared browser): the first user's row is removed.
- 11th device evicts the least recently seen, count never exceeds 10 under two concurrent subscribes.
- A tick that fires twice, or a catch-up of the previous slot, never marks a reminder sent twice in a day.
- `"24:00"`, `"7:5"`, `""`, `"12:07"` as a reminder time: reject the first three; `"12:07"` rounds down to slot 48.
- DST: BRT has none today, but slot maths must use the zone, not `UTC-3`.
